# ממיר וידאו אופליין

אפליקציית Android לסריקת תיקייה שנבחרה ולהמרת סרטונים לקובצי MP4 עם וידאו H.264 ושמע AAC.

## גרסה 1.1 — מנוע FFmpeg

- משתמשת במנוע FFmpeg מקומי במקום להסתמך רק על מפענחי Android.
- כוללת תמיכה בפענוח מגוון רחב יותר של קובצי וידאו ואודיו.
- מייצאת MP4 עם H.264 באמצעות OpenH264 ו-AAC.
- סורקת גם תיקיות משנה.
- שומרת את התוצאות ב-Movies/Converted.
- ההמרה מתבצעת במכשיר ואינה מעלה סרטונים לאינטרנט.

## התקנה ושימוש

1. מתקינים את קובץ ה-APK.
2. בוחרים תיקייה ומאשרים גישה.
3. לוחצים על "סריקה והמרת כל הסרטונים".
4. ממתינים לסיום. הקבצים המומרים נשמרים בתיקיית Movies/Converted.

## תאימות חשובה

- חבילת FFmpeg שנבחרה לגרסה זו מסופקת עבור arm64-v8a בלבד. לכן הגרסה מיועדת לטלפונים ומכשירים מודרניים עם מעבד ARM64; אמולטורים מבוססי x86_64 כגון חלק מתצורות BlueStacks עלולים לא להיות נתמכים.
- FFmpeg מרחיב את התמיכה בפענוח, אך אינו מבטיח הצלחה עם כל קובץ: קבצים פגומים, DRM, פורמטים חריגים או קובץ שאין בו זרם וידאו תקין עדיין עלולים להיכשל.
- הקידוד מתבצע באמצעות OpenH264. איכות, מהירות וגודל הקובץ תלויים במקור ובביצועי המכשיר.

## בנייה

GitHub Actions builds a debug APK on every push to `main`. Download it from Actions → latest workflow run → Artifacts.

## רישוי

הספרייה ffmpeg-kit-full משולבת בגרסת LGPL של FFmpegKit maintained fork. יש לעיין ברישיונות ובהודעות צד שלישי המצורפים לספרייה לפני הפצה ציבורית.
