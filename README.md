# ממיר וידאו אופליין

אפליקציית Android לסריקת תיקייה שנבחרה ולהמרת סרטונים ל-MP4 (H.264/AAC) באמצעות Media3 Transformer.

## בנייה

GitHub Actions builds a debug APK on every push to `main`. Download it from Actions → latest workflow run → Artifacts.

## שימוש

1. מתקינים את ה-APK.
2. בוחרים תיקייה פעם אחת ומאשרים גישה.
3. לוחצים על סריקה והמרת כל הסרטונים.
4. הקבצים המומרים נשמרים בתיקיית Movies/Converted.

ההמרה מתבצעת מקומית במכשיר. התמיכה בפורמטי מקור תלויה ביכולות הפענוח של Android והמכשיר.
